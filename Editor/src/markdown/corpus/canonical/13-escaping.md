Identifiers stay as they are: snake_case_name, my_var__name, a_b_c_d and MAX_RETRY_COUNT.

Comparisons stay as they are: a < b & c > d, x <= y, 1 < 2 > 0, AT&T, R&D, Q&A.

URLs stay as they are: https://example.com/my_file_name?user_id=1&sort_by=created_at

Tags and counters: #idea #todo and item #1, C# too.

Brackets: [WIP] draft, array[0], see [1] and [2], f(x)[y].

Tildes: ~5 min, ~/Documents/UltraNote, a~b.

Dots: view.state, window.location, e.g. this and 3.14.

Math-like: 2 + 2 = 4, 50% off, $100, a^2, {braces}, a | b.

Literal tags are text: \<kbd>Cmd\</kbd>, \<br>, \<!-- comment --> and \<a href="x">.

Literal character references are text: \&amp; \&lt; \&#38; \&#x26; \&copy;

Literal markup is text: \*not italic\*, \*\*not bold\*\*, \_not italic\_, \`not code\`, \~\~not struck\~\~, \_\_init\_\_.py.

Literal link syntax is text: [text]\(https://example.com) and \![alt]\(image.png).

Backslashes: C:\Users\name, a \ b and a literal \\\*.

\# Not a heading

\- not a list item

\+ not a list item either

1\. not an ordered item

\> not a quote

\[not a definition]: https://example.com
